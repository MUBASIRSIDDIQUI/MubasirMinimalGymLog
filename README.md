# Mubasir’s Minimal Gym Log 💪

A clean, no-BS workout logging app based on Mubasir’s personal 5-day training split.  
Built with SwiftUI and Firebase to help you stay consistent and focused at the gym.

## 🚀 Features
- Pre-loaded 5-day gym split (Push, Pull, Legs, Upper/Lower Hypertrophy)
- Log sets and reps per exercise
- View workout history
- Clean minimal UI – nothing extra
- Offline-first (Firebase sync coming soon)
- Upgrade for full plan via in-app purchase

## 🛠 Tech Stack
- SwiftUI
- Firebase
- RevenueCat (In-App Purchases)
- MVVM Architecture
